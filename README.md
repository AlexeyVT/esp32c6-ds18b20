# DS18B20 to zigbee adapter (ESP32 C6)
Устройство zigbee, использующее GPIO (1 по умолчанию) для чтения 1-wire шины, поиска термосенсоров DS18B20. 
Считывает каждые 5 секунд показания. 
Если показания изменились, обновляет значения.

Отчёты (Report Attributes) устройство настраивает само, по каждому датчику, а отправляет их стек: reporting, заданный
координатором, привязан к конкретной конечной точке, поэтому конечные точки без такой настройки не обновлялись бы.
Своя настройка — минимум 10 с, максимум 3600 с, порог 0.25 °C, получатель — координатор; координатор может её
переопределить.

Если при старте на шине не найдено ни одного датчика, регистрировать в Zigbee нечего, поэтому стек не запускается:
устройство в сеть не выходит, светодиод пурпурный, до перезагрузки с подключённым датчиком.

В качестве платформы использован WeAct ESP32-C6-MINI c NeoPixel, на котором сделана индикация состояния:

- Жёлтый - конфигурация
- Красный - ошибка подключения к сети zigbee
- Зелёный - чтения показания DS18B20
- Пурпурный - ошибка чтения DS18B20: перестал читаться датчик, найденный при старте, либо не читается ни один датчик

Устройство работает как end-device (node)

## Реестр конечных точек

Номер конечной точки закреплён за ROM-адресом датчика и хранится в NVS (namespace `ds18b20`), поэтому при замене датчика
номера остальных конечных точек не меняются:

- при первой загрузке реестр заполняется текущим порядком сканирования (ROM-адреса по возрастанию), поэтому для уже
  спаренного устройства номера остаются теми же;
- на каждой загрузке реестр приводится в соответствие шине: найденные датчики сохраняют свои номера, записи отсутствующих
  датчиков удаляются и забываются;
- новый датчик занимает освободившийся номер: при одной замене он получает номер выбывшего, при нескольких заменах номера
  раздаются в порядке ROM-адресов, а лишние датчики получают низший свободный номер;
- забытый датчик, подключённый снова, регистрируется как новый и может получить другой номер;
- датчик, переставший читаться уже после старта, отдаёт 0x8000 (значение неизвестно) и зажигает пурпурный, а при следующей
  перезагрузке будет забыт, если не появится на шине;
- изменение состава датчиков меняет набор конечных точек, поэтому координатору нужен повторный опрос (re-interview);
- реестр рассчитан на 32 датчика.
