# DS18B20 to zigbee adapter (ESP32 C6)
Устройство zigbee, использующее GPIO (1 по умолчанию) для чтения 1-wire шины, поиска термосенсоров DS18B20. 
Считывает каждые 5 секунд показания. 
Если показания изменились, обновляет значения.

В качестве платформы использован WeAct ESP32-C6-MINI c NeoPixel, на котором сделана индикация состояния:

- Жёлтый - конфигурация
- Красный - ошибка подключения к сети zigbee
- Зелёный - чтения показания DS18B20
- Пурпурный - ошибка чтения DS18B20

Устройство работает как end-device (node)

## Реестр конечных точек

Номер конечной точки закреплён за ROM-адресом датчика и хранится в NVS (namespace `ds18b20`), поэтому при замене или
пропаже датчика номера остальных конечных точек не меняются:

- при первой загрузке реестр заполняется текущим порядком сканирования (ROM-адреса по возрастанию), поэтому для уже
  спаренного устройства номера остаются теми же;
- если с шины пропал ровно один известный датчик и появился ровно один новый, новый занимает конечную точку выбывшего;
  замена определяется только при перезагрузке;
- остальные новые датчики получают низший свободный номер, при нескольких заменах сразу наследования нет;
- конечные точки известных, но отсутствующих на шине датчиков остаются зарегистрированными и отдают 0x8000 (значение неизвестно);
- реестр рассчитан на 32 датчика.
